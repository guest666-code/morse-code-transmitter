# 📟 Retro Morse Code Generator & Transmitter

A lightweight, retro terminal-styled web application built with pure Vanilla JavaScript, HTML5, and CSS3. It converts input text into Morse code in real-time and synthesizes retro audio beeps using the native **Web Audio API**.

---

## ✨ Features

- **Real-Time Morse Translation:** Instantly converts typed text into standard Morse code formatting.
- **Web Audio API Synthesizer:** Generates dynamic 700Hz sine wave audio beeps on keypress without relying on external `.mp3` files.
- **Retro CRT / Terminal Theme:** Custom neon-green dark theme with glow effects and responsive layout.
- **Zero Dependencies:** Built entirely with vanilla Web Technologies — fast, clean, and lightweight.
